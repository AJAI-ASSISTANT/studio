# STUDIO

An event planner, a 3D room studio and an invoice maker, in one page.

**https://studio.thefinerthingsevents.com**

Open the link. There is nothing to install, no account and no server.
Everything you enter stays in your own browser.

The page is `index.html` and it is the whole application — the same single
file that can be downloaded and opened offline. It is published here because
Gmail refuses to send `.html` attachments, so a link travels where the file
cannot.

Built by The Finer Things Events.
